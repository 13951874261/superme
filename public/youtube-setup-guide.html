YouTube 转写 · 新手操作手册

按本手册操作一次，即可在网页粘贴 YouTube 链接自动转写。B 站链接无需配置。

一句话说明：服务器需要借用你电脑上的 Clash 代理和 Chrome 登录状态，才能下载 YouTube 音频。配置一次约 2 分钟。

开始前请确认

  • 使用 Windows 电脑
  • Clash / Clash Verge 已打开，浏览器能访问 YouTube
  • Chrome 已登录 YouTube 账号
  • 本机有 Python 3（没有可到 python.org 安装）

第一次配置（5 步）

  1. 打开应用 → 视频字幕 → 在链接框右侧点击 「下载配置」
  2. 解压 zip 到桌面或任意文件夹
  3. 双击 setup-youtube.bat
  4. 首次按提示输入 SSH 密码（仅保存在本机）
  5. 脚本完成后，回到网页点 「检测就绪」，变绿即可提交链接

日常使用

  • 电脑重启后：运行 keep-youtube-tunnel.bat（窗口可最小化）
  • 约 2 周后：重新运行 setup-youtube.bat 刷新 cookies
  • Clash 关闭或隧道窗口关闭 → YouTube 转写会失败

常见问题

Q：检测显示「代理未连通」？

A：打开 Clash，运行 keep-youtube-tunnel.bat。

Q：检测显示「cookies 无效」？

A：Chrome 登录 YouTube，关闭所有 Chrome 窗口后重新运行一键配置。

Q：B 站需要配置吗？

A：不需要，直接粘贴 B 站链接即可。
