| **LS-CASE-02** | 洞察(听) | 对白按语速 ≈**8–10 分钟**（约 2100–2600 字 / `scriptEvaluator`）；**结构化长剧本**（角色/表面诉求/隐藏底牌/完整对白）；**强复用**工坊类型+校验；听模块换皮展示+侧写；不足则**降级展示并标注未达 8–10 分钟** | 听模块**不开**多人会话、**不**导入对战沙盘 | `brainstorming` → `writing-plans` → `surgical-modification`；验证 `browser-test-analyzer` |

| **RD-LEN-01** | 穿透(读) | 「每日 AI 素材推送」正文 ≥ **1500** 字；不足则**降级展示+标注**，可手动再推 | 本轮不以「结构字段齐全」作硬卡（可后续加） | `analyze`（推送 API/prompt）→ `writing-plans` → `surgical-modification` |
| **GT-CASE-02** | 驭心博弈 | 案例：`background` ≥ **400** 字 + 多方角色/不完整信息/决策点；研判：**强制分节**（利益链/情绪动机/可执行策略/话术示例）且 ≥ **600** 字（含情绪判断+可执行建议）；不足则降级标红 | — | `analyze`（push + 研判 prompt）→ `writing-plans` → `surgical-modification` |
| **GT-SIM-02** | 驭心沙盘 | **经典人机沙盘 + 多人会话**均需独立「语气修正」；形态为对比表：**原话 \| 问题 \| 建议说法** | 不得仅并入 `strategy_guidance` 而无独立区块 | `analyze`（两处研判契约）→ `writing-plans` → `surgical-modification` |
| **GT-TAC-视频** | 驭人术 | 上传视频 → **转写 + 抽手段入库 + 可回看**；**本机上传存服务器**（限体积/时长），**任务中心异步** | 本轮不做「仅 URL、不落盘」方案 | `analyze`（复用英语转写管线）→ `writing-plans` → `surgical-modification` |
| **AE-JUD-01** | 高阶审美 | **防串台验收**：须输出社交指数/点评类字段；用户未亲眼见「单词解释」串台，**不按该缺陷重写** | 不为「单词解释」单独改版（除非复现） | `browser-test-analyzer` / 手工复验 → 必要时 `systematic-debugging` |
| **AE-TIP-01** | 高阶审美 | 选中场景后实操要点 ≥ **5** 条 | — | `analyze` → `surgical-modification` |
| **PERF-01** | 全站 | **前端**：切 Tab/折叠不假死；**生成**：异步、任务中心可追踪、失败可感知；**本轮一起验收** | — | `systematic-debugging`（任务失败）→ `analyze`（前端）→ `surgical-modification`；验证 `browser-test-analyzer` |
| **导出速度** | 驭心+抽屉 | 驭心手段库导出 **与** 资料抽屉导出：点击后**立刻进任务中心**，完成后下载，**不堵 UI** | 不设「必须 ≤N 秒同步下载」 | `analyze` → `writing-plans` → `surgical-modification` |
| **资料格式** | 资料抽屉 | **docx + CSV**（Excel 可打开）即合格 | **不强制**原生 `.xlsx` | 格式本轮可不单独立项；遮罩点不到用 `systematic-debugging` |
| **EN-PART** | 英语分区 | **仅 UI/默认**：默认落政务轨道；文案写清「时间紧先做政务」 | 不做算法加权；**不**恢复强制锁定全场景 | `surgical-modification`（默认轨道+文案） |
